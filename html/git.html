Основные команды в Git

Работа с репозиторием

  • git init — создаёт новый локальный репозиторий в выбранной папке.
  • git clone — клонирует удалённый репозиторий и создаёт его локальную копию.
  • git status — отображает актуальное состояние файлов в рабочем каталоге.
  • git add — добавляет файлы в индекс (подготавливает к коммиту).
  • git commit -m «Описание изменений» — фиксирует изменения (создаёт коммит) с комментарием, описывающим суть внесённых правок.

Ветви

  • git branch — создаёт новую ветку, оставаясь при этом в текущей.
  • git checkout — переключается на указанную ветку.
  • git merge — объединяет выбранную ветку с текущей, добавляя её изменения.

Удалённые репозитории

  • git push — передаёт сделанные локально изменения в связанный удалённый репозиторий для их сохранения и совместной работы.
  • git pull — получает изменения из удалённого репозитория и автоматически сливает их с локальной веткой.
